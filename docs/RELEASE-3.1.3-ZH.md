# ZotQuery 3.1.3

修复点击“API 研究并生成”时的 `nsILoginManager::addLogin` 错误。

- 新 API Key 使用 Zotero 10 的 `addLoginAsync` 保存。保存配置、保存按钮和报告生成入口均等待保存完成。
- 更新已存密钥时使用 `modifyLogin`，不再先删除旧密钥。写入失败时保留原密钥，界面保留输入以便重试，并显示失败信息。
- 思考强度在写入任何配置或密钥前校验；密钥保存失败时不写入本次普通配置。
- 移除附带的 Markdown 输出模板及写作模板文档。用户必须自行导入 `.md` 文件；缺失或不可读时生成前报错，不回退到内置模板。
- 保留用户导入模板全文输入、模型思考强度及研究证据门禁。
- 证据台账卡片和上下文面板增加父条目、所属分类目录、来源/关联笔记及 PDF 原文链接。唯一 PDF 且有页码时跳转物理页；多 PDF 不猜测来源，分别提供附件入口。语段和笔记行号保留在界面，可复制原文查找，未声称自动高亮任意语段。
- 工具栏与工作台左上角统一使用 ZotQuery 插件图标。

接口依据：本机 Zotero 安装中的 `modules/LoginManager.sys.mjs` 与 `chrome/content/zotero/xpcom/storage/webdav.js`；官方迁移说明：https://www.zotero.org/support/dev/zotero_8_for_developers 。

回归覆盖新增/更新/清除密钥、写入延迟、写入失败后保留旧密钥、读取失败、跨提供商隔离，以及实际工作台按钮的异步成功/失败处理。所有测试使用虚构凭据，不读取用户密钥。

交付验证为源码、模拟接口回归与发布包验证；尚未在运行中的 Zotero 安装此版本并调用真实模型 API。
