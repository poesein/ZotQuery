# ZotQuery 3.1.22

- 修复 PDF 看图链路的超时后后台渲染未取消问题：超时会取消 PDF.js 的页面任务、销毁加载任务并移除隔离渲染器；失败不登记为已看图。
- 整页默认以 1600 px 预览、局部区域以 1800 px 读取；超时后分别以 1050/1200 px 自动降档重试，返回实际尺寸与降档标记，不把低清内容当成已辨清的小字。
- ChatGPT 页面预览和插件内模型读图共用一个 48 MiB 的运行期栅格缓存；同页同区域的并发调用合并，其他重型渲染串行且队列等待有上限。
- 图像结果附带缓存、分辨率、回退和 PDF.js 阶段耗时诊断，不包含文献文字或本地路径。

本版本未改 Zotero 原始 PDF、注释、研究证据门禁或用户模板。运行期缓存会在 Zotero 重启后清空，已保存的视觉证据仍按原机制持久化。
