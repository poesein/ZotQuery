# ZotQuery 3.1.15

本版更新研究编排、可追溯的 PDF 看图链路、研究历史删除和模型请求生命周期。更新为通用能力，不针对某个研究问题写规则。

## 研究与回答

- 明确区分“全流程核验完成”与“某个子问题已有原文支持”。先回答有出处且带适用限定的部分，再列未解决事项；缺少另一个槽、覆盖或登记不应抹掉已支持的结论。
- 区分作者直接报告的对应关系与对其性质的进一步推断；不把构象/条件差异机械等同于数值全部无效。
- 研究工具批次后补充具体待办导航：尚未读/审的位置、未闭合槽、Note→PDF 编排游标。进入写作、补查后和保存前由插件调用实际 finalize，不依赖模型记得收尾，不修改核验通过条件。
- 导入模板仍只控制格式，原文件不改动。模板中的流程性文字不应禁止带限定的部分回答；无原文或没有实际看图时不得编造结论。

## PDF 看图

在“ZotQuery 设置 → 输出大模型与 Markdown 模板”启用“允许按需向模型发送 PDF 页面／区域图片（API 与 MCP）”，使用支持图像输入的模型。默认关闭；普通连接测试不证明视觉识别能力，图片请求可能增加服务商用量。

- `evidence_page_image` 读取指定 PDF 物理页（从 1 开始），可指定从显示页面左上角开始的归一化区域。先看整页定位，再裁剪，并保留行名、图例和编号。多 PDF 附件时要求明确 attachmentKey，不猜测附件。
- 使用 Zotero 随附 PDF.js，在隔离的本地渲染文档中生成 PNG；不创建 PDF 批注、不修改原文件、不依赖用户当前选中或已打开的 PDF 页。
- OpenAI 兼容、Anthropic、Gemini、Ollama 请求各自使用原生图片字段；MCP 返回 image 内容块，图片编码不冒充文本原文。
- 本地保存页面截图、页码、区域、文件指纹和图像摘要。相同来源与区域复用截图，源 PDF 改动后生成新记录。会话恢复需重新获取图片，不把历史描述称为本轮看图。
- `evidence_visual_observe` 保存行/轴标签、编号、可见观察与疑点，独立于文本逐字核验事实；`evidence_visual_list` 分页返回记录。保存截图不等于模型已完成审阅，视觉判断不自动闭合 EXACT 槽。
- 证据页新增图像记录列表，可查看截图和跳转 PDF 原页；裁剪区域在记录中保留。未启用、附件不明确、文件/页码无效或渲染失败时明确报错，不标记为文字已读。
- 不进行全篇默认图片上传，不调用额外的视觉服务商，不宣称执行了 OCR；读取能力取决于所选模型和路由。

## 历史删除

每项历史记录有“删除”。确认后事务删除该研究的全部回答版本、证据位置、事实与评估、已读分页记录、图像及视觉观察，并清除其进程内续跑缓存。运行中的研究禁止删除。不可撤销；原始 Zotero 文献/PDF/笔记、共享索引/Survey 缓存、个人模板及已导出的文件不删除。升级本身不删除任何现有研究。

## 请求生命周期

OpenAI 兼容请求使用 SSE，显示实际接收字符数与等待时间，不把字符当 token 或把心跳当模型思考进度。保留 DeepSeek 思考元数据和完整工具回传；只有完整终止响应才采纳答案或执行工具。网关在同一请求忽略 stream 而返回 JSON 时可接受完整 JSON，不额外重发。

所有请求增加独立总超时和“停止并保留”。显式禁用 Zotero HTTP 层隐含的 429/5xx 重试，避免底层重试拉长等待或重复计费；保留原有有界的输出预算重试与上下文恢复。停止客户端请求不保证服务商停止计费。流断开、缺少终止标记、参数不完整或截断响应均不保存为完整答案。

## 验证边界

- 99 项离线测试及模型切换回归通过：真实 SQLite、原生行代理、事务回滚、历史/图片删除、图片权限/来源绑定/缓存、四类 API 图片格式、MCP 图像块、部分回答规则、自动核验刷新、SSE、超时/取消、本地分块 HTTP 等。
- 使用当前 Zotero 随附 PDF.js 对本地 PDF 完成整页与区域渲染，并查看生成图像，核对标签、编号和区域位置。该测试通过 Node/Canvas 适配运行，不等于原生 Zotero 窗口端到端验收。
- 隔离 Zotero 配置未成功加载临时测试扩展，原生渲染窗口及真实服务商视觉回答仍需安装后验收；未调用付费模型、未安装到日常配置、未重启日常 Zotero、未发布 GitHub。
- README、个人模板、实际研究数据库及旧版本发布包保持不变。包内不含测试截图、个人文献、真实研究报告、会话、日志、凭据或模板。

## 建议验收

安装后启用看图，用一份已知图表所在页的 PDF 进行研究。日志应分别显示文字读取和 PDF 图像读取；图像记录应能打开正确截图、跳回原页。模型应在回答中引用具体页和限定，而不是把所有子问题都称为无法确认。删除一项不需要的研究前确认已有必要导出；其他研究及原始文献应保持可用。
