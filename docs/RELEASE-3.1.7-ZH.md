# ZotQuery 3.1.7：回答默认渲染

保留 3.1.6 的单列界面、一键自动取证和设置迁移，回答正文默认以渲染后的 Markdown 展示，不再直接显示源码。

- 标题、粗体、斜体、列表、引用、代码块、表格与链接按阅读格式排版。
- 点击“Markdown 源码”编辑原文；返回“阅读”立即重新渲染。
- “复制回答”和“保存 .md”仍使用原始 Markdown（含用户编辑），不复制网页 HTML，不混入证据台账。
- 每次新答案生成后自动进入阅读模式。空答案和源码清空不会残留上一份渲染内容。
- 保留安全的 HTTP(S) 与 Zotero 文献/PDF 链接；任意 HTML 标签只显示为文本，不执行脚本、不插入事件属性，外部图片不自动加载，仅提供可点击的安全链接。原始 HTML 注释在阅读中隐藏，但保留于导出的 Markdown。

解析采用本地捆绑的 Marked 17.0.5 词法分析器，只从令牌建立允许的 DOM 元素；不依赖 CDN、外部渲染服务或用户密钥。MIT 许可文件随包附带。本版不包含数学公式引擎；公式保持文本表达。

8 个离线回归测试文件通过，新增渲染格式、表格、HTML/XSS 隔离、链接白名单、源码修改及默认阅读模式回归。静态浏览器预览检查了真实渲染、源码切换、表格重渲染和不同窗口宽度。XHTML/XML、JavaScript、包与源码文件一致性、私有模板排除已检查。

尚未自动安装到 Zotero 或调用真实 API；浏览器预览为模拟数据，不能替代原生 Zotero 10 与实际服务验收。旧版、用户模板和既有索引均未改动。
