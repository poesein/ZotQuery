# ZotQuery 3.1.26

此版本新增文献库规整接口，并保留原有证据研究与深度精读流程。

- 新增分页标签盘点、条目组织状态、标签与集合变更预览、建集合预览、结构化元数据导入预览和计划提交，共 6 个原生 MCP 接口。
- 所有变更按明确的文库和条目键定位。预览不写入；提交时复核原状态，并返回回执。`✅精读完成` 仍由 Depth QC 流程管理。
- 网页 ChatGPT bridge 的契约更新为 v2，向精简和完整视图暴露新接口。
- [文献库规整说明](LIBRARY-ORGANIZATION-ZH.md)列出范围和操作顺序。

验证：152 项自动测试通过；既有 Zotero 配置中原生 MCP 返回 73 个工具，ChatGPT bridge 的精简和完整视图分别返回 41 与 86 个工具；文库盘点、条目读取及无变更预览完成只读实测。尚未在真实文库提交写入计划，也未在网页 ChatGPT 新会话执行工具调用。
