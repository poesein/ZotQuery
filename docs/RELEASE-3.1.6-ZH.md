# ZotQuery 3.1.6：以回答为中心的研究工作台

## 新布局

取消固定左右栏，以单列“问题 → 进度 → 回答 / 证据”组织工作台。蓝色标题栏、紧凑字体、连续证据行参考 ZotRadar 5.4.1，本插件仍保留自身的证据阅读和核验流程。

- 顶部输入问题，点击“大模型回答”（或 Ctrl + Enter）。自动建立证据会话并检索，然后让 API 模型调用内置工具阅读、审阅、核验，最后单独撰写回答。不需要先点击创建会话或加载证据。
- 默认主视图为回答正文，可编辑、复制、保存 .md。证据台账另页查看；切换至该页会自动加载证据，保留父条目、目录、笔记、PDF 页和原文上下文入口。
- 删除独立的“检索与筛选”页、重复统计卡、大段流程说明和模型配置侧栏。底层检索及 MCP 工具保持不变。
- 进度压成一行；研究策略、人工会话、FactRecord、运行记录、索引详情及内部台账按需展开。

## 设置迁移

在“Zotero 设置 → ZotQuery → 输出大模型与 Markdown 模板”设置服务商、API 地址、模型、密钥、思考强度、工具轮数、超时，并测试连接。模板可选，用户导入的 .md 全文会作为格式参考传给模型；不导入也能回答。

BGE 等向量模型继续使用同一设置页的“共享向量模型”，与输出模型分开配置。原有偏好键、API 凭据和模板路径保持不变，无需重新迁移数据。API 测试不会代替保存；保存成功后清空密码输入框，但不会删除已保存的凭据。返回工作台会刷新配置摘要；开始研究使用已保存配置，不再由工作台覆盖设置。

“默认研究输出格式 / Output Profile”属于证据台账格式，不是大模型 .md 模板。

## 一键操作边界

“证据索引”在本次流程中指针对问题检索已有 PDF/笔记索引并建立研究证据会话，不是每次重建整个文库。尚未建立基础索引的文库仍需在设置中完成索引。会话签名包含原始问题和研究策略；改变问题或策略会建新会话，不会误用上一题证据。同一问题可继续当前会话。生成期间禁止重复启动及修改本轮问题策略。

模型能力、语料和工具轮数仍可能导致未完成核验；此时回答会说明限制，不会伪称已读完全部文献或确认精确事实。仅索引命中不等于阅读，台账不替代模型回答。

## 验证与分发

7 个离线测试文件通过：模型提供商与凭据、工具调用与门禁、设置异步保存与重试、模板字符串/nsIFile 路径与取消、原文链接、单击自动取证和会话隔离、Markdown 正文导出、DOM 控件契约及既有索引回归。XHTML/XML 和 JavaScript 语法检查通过。

静态浏览器预览使用模拟数据，验证回答和证据页、单击生成链路及 500/720/980/1180 px 布局；不是 Zotero 原生窗口实测或真实 API 调用。未自动安装、重启 Zotero 或修改已有索引。分发不包含用户私有 .md 模板，旧版发布包未改动。
