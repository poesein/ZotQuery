# ZotQuery 3.1.17

在 3.1.16 的研究台与自动预算改动基础上，修复两处实际界面问题：

- 研究历史的“打开 / 续跑”和“删除”按钮改用独立操作容器，不再占用同一网格单元；窄窗口中移至条目下方。
- 设置页的原生按钮采用明确的高度、内部居中与水平居中规则，处理文字偏向按钮底部的问题。
- Survey 笔记到同父 PDF 的导航分页默认从 12 提升到 50 篇。模型收到有明确省略标记的简短分页摘要，完整结果仍保留在会话台账；需要证据时继续从 PDF 位置读取原文。这样减少大量笔记候选消耗的模型轮次，同时不把导航摘要当作已读证据。
- 已读且审阅为支持或部分支持的 PDF 位置，若尚无 FactRecord，会进入后续行动列表。模型因此能优先回到原文登记带范围判断的事实，而不会把所有轮次用在更广的笔记导航上；这个列表本身不自动生成事实。

完整变更及 3.1.16 的自动预算、响应解析、传输保护见 `RELEASE-3.1.16.md`。

验证：115 项离线回归通过，包括 50 篇分页摘要的协议与证据边界、已审阅 PDF 的待登记事实导航；浏览器布局预览核对 1180 px 和 440 px 的历史按钮不重叠，设置页概览按钮置中。原生 Zotero 设置页仍需安装后的视觉验收。更新安装包时，应先让正在运行的研究完成；不要中断、删除或覆盖历史会话。

真实研究观察（使用已安装的 3.1.16，并非 3.1.17 安装验收）：一次实际 API 研究完成并保存模型回答，本次没有重现空响应、截断或请求超时。但因精确事实门禁要求文本字面型 DIRECT 证据，而模型只登记了图读推断，研究状态仍为 limited。3.1.17 的通用导航修复针对本次观察到的 Survey 提升分页耗轮次和已审阅原文迟迟不登记事实；它不改变图像观察不能直接充当文本事实的证据边界，也未在付费模型上重新运行整轮验收。
