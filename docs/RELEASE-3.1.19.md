# ZotQuery 3.1.19

本次更新扩展私有 ChatGPT MCP 只读连接，不改变 ZotQuery 研究台的研究/核验写入流程。

- 新增历史答案版本与答案片段、候选 PDF、PDF 索引正文分页和文内字面定位工具。所有文献读取都限定在指定研究会话内，且不会把位置标记为已阅读、已列出或已核验。
- 已保存图像工具默认可见；新增原始 PDF 页面/区域临时看图工具。临时渲染不保存新视觉证据、不修改 PDF 和台账状态；ZotQuery 的“支持图片”设置仍可禁止实际读取。
- 本机适配器响应保护上限从 2/16 MB 提高到文本 64 MiB、图像编码 96 MiB。大材料优先分页与按需读取；隧道、ChatGPT 和模型上下文仍可能施加更小限制，超限不会静默截断。
- 保留仅本机 Bearer 校验、研究会话范围校验和适配器工具白名单；没有向 ChatGPT 开放核验、事实登记、删除或其他写入工具。

本版本源代码和 XPI 的离线测试不能替代实际 Zotero 安装、ChatGPT 连接和图片读取验收。用户导入的 Markdown 模板、研究数据库、令牌和个人文献不属于发布包。
