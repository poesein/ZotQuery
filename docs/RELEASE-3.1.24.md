# ZotQuery 3.1.24

- 增加按 collection key 分页浏览顶层文献，以及每页 1–10 篇的精读批次状态：PDF 可用性、管理笔记、完成标签、失败原因与冲突状态。
- 增加 `zotquery_upsert_child_note`：以文献库、父文献 key 和 `readingProfileId` 识别同一篇精读笔记，重复提交不再建副本；只更新 ZotQuery 自己管理且未经人工修改的笔记。笔记保存并确认父子关系后，在同一数据库事务中给父文献添加 `✅精读完成`。
- 增加受限的 `zotquery_set_item_tag` 和逐篇失败记录；重试成功清除失败记录。外部同名笔记、人工改动、已打标签但无受管理笔记等状态须人工核对，不会自动覆盖。
- ChatGPT 紧凑工具面公开上述读写接口，写入标注为非只读，研究证据台账写入仍不开放。客户端刷新工具及逐次确认行为仍需现场验证。

`readingProfileId` 是写入幂等标识，**不是**精读输出模板的执行器。既有 Note Profile 只解析笔记。模型必须先实际读取用户自己的精读 Markdown 模板和原文，完成核验后再提交 HTML 笔记。此版本不打包任何私人模板或私人数据，也不自动批量生成未经核验的内容。
