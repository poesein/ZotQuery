# ZotQuery 3.1.8

## 内置 API 研究与 Markdown 阅读

- 单列研究工作台与独立工具栏入口。输入问题后点击“大模型回答”，自动建立研究证据会话，使用已有 PDF/笔记索引召回证据，再让模型通过内置 MCP 等价工具阅读、审阅、核验并撰写回答；无需手动先建会话，不会每次重建全库索引。
- 输出模型支持 Ollama、DeepSeek、OpenAI、Anthropic、Gemini、通义千问和第三方 OpenAI 兼容接口。API 地址、模型、密钥、思考强度、轮数与超时统一在 ZotQuery 设置中管理。BGE 等向量模型与输出模型独立配置。
- 回答默认渲染 Markdown，支持标题、表格、列表、引用、代码块和安全来源链接；可切换源码编辑、复制或保存 .md。内部台账独立展示，不替代或混入回答。
- .md 输出模板由用户自行导入，全文作为格式参考传给模型；没有模板也可回答。发布包不附带私人模板。
- 证据台账保留父条目、所属分类目录、笔记和 PDF 页链接，以及原文上下文、审阅和精确事实记录。

## 隐私与兼容性

输出 API 密钥保存在 Zotero Login Manager，不写入普通偏好、源码或安装包。远程模型会接收本次研究工具返回的相关文献片段，使用前请确认服务的数据保留与计费政策。Markdown 渲染不会执行任意 HTML/脚本或自动加载远程图片。

分发只包含程序、通用格式配置、测试和文档，不包含 Zotero 文献库、笔记/PDF、用户模板、数据库、运行日志、账号凭据或个人目录。当前源码移除旧版附带的输出模板文档，提供构建前隐私扫描。历史提交和旧版附件不因本次更新自动消失。

升级保留同一扩展 ID、偏好和索引。问题或研究策略改变时建立新会话；核验未完成时只提供有明确限制的阶段性模型回答。模板不改变证据标准，检索数量不等于阅读数量。

## 安装与验证

从本 Release 附件下载 `ZotQuery-3.1.8.xpi`，通过 Zotero 插件管理器从文件安装。源码包与 SHA-256 校验表在同一发布页。

离线回归覆盖模型请求与凭据、模板导入、会话隔离、一键研究、原文定位、Markdown 格式和脚本隔离、源码编辑与正文导出；同时检查 JavaScript/XML、分发隐私、包与源码一致性。静态预览使用模拟数据。尚未在此发布流程中完成 Zotero 10 原生安装、真实 API 联机或全新 profile 验收，不能把离线通过等同于全部运行环境已验证。

README 及其现有图片按维护者要求保持不变；本页是本次功能与验收范围说明。
